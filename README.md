🎨 Cutesy Aesthetics

Art. Creativity. Cuteness.

Cutesy Aesthetics is a creative website built for showcasing artwork, crochet pieces, sketches, handmade products, and creative content.

The website combines a portfolio, shop, and social-style feed into one place, allowing visitors to explore the creator's work and see what is available.

✨ Features

- 🎨 Artwork gallery
- 🧶 Crochet collection
- 🛍️ Online shop
- 📱 Social-style feed
- ❤️ Likes
- 💬 Comments
- 🔖 Saved posts
- 👤 User accounts
- 🛒 Shopping cart
- 📦 Orders
- 📸 Image and short-video posts
- 🔎 Gallery categories and filtering
- 📱 Responsive mobile design
- ⚡ AJAX page loading

🛠️ Built With

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Font Awesome
- Google Fonts

📖 How It Works

Feed

The feed is where the creator can share artwork, sketches, progress, short videos, behind-the-scenes content, and other updates.

Gallery

The gallery is for finished creative work. Visitors can browse artwork, crochet pieces, and sketches using the category filters.

Shop

The shop contains products that are available for purchase. Products can also be connected to posts and gallery items.

Accounts

Visitors can browse the website without an account, while an account is required for features such as commenting and purchasing.

🗄️ Database

The website uses MySQL to store information such as:

- Users
- Posts
- Products
- Categories
- Comments
- Likes
- Saved posts
- Follows
- Orders
- Payments

🎯 Project Goal

The goal of Cutesy Aesthetics is to create more than a simple art portfolio.

It brings the creator's artwork, handmade products, and social content together in one website while also serving as a real-world project for learning and experimenting with web development.

🚧 Project Status

Cutesy Aesthetics is currently under development.

The main website structure and database are in place, while individual features and the mobile experience continue to be improved.
